Entry for the make.fun bounty [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

`main.py` (Python standard library only, no network, deterministic) writes one line — the funniest excuse an AI agent can give after failing a task — to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`).
